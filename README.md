# タイムスケジュール

1日のタイムラインでスケジュールを管理する PWA（Progressive Web App）。

## 機能

- **タイムライン表示** — 24時間の時間軸に沿って、その日の予定を表示。今日は現在時刻に赤いラインが出ます。
- **単発の予定** — 特定の日付だけのイベント。
- **繰り返しの予定** — 曜日を指定して毎週繰り返すルーティン。
- **編集・削除** — 予定をタップして内容を変更、または削除。
- **色分け** — 6色から選択。時間が重なる予定は自動で横並び表示。
- **通知** — 開始時刻にブラウザ通知（アプリを開いている間のみ）。
- **オフライン対応** — Service Worker でキャッシュするため、電波がなくても開けます。

データはすべてブラウザの localStorage に保存されます。サーバーには一切送信されません。

## iPhone でホーム画面に追加する

1. Safari で公開URLを開く
2. 下部の共有ボタン（□に↑）をタップ
3. 「ホーム画面に追加」を選択
4. 名前を確認して「追加」

これでアプリのように全画面で起動します。

## ローカルで動かす

```bash
node serve.js
```

http://localhost:5173 で開きます。

## 通知について

iOS の標準「時計」アプリのアラームに、外部アプリからプログラムで予定を追加する公開APIは存在しません。そのためこのアプリは自前のブラウザ通知でお知らせします。

iOS でプッシュ通知を使うには、**ホーム画面に追加したうえで**そのアイコンから起動する必要があります（iOS 16.4 以降）。Safari のタブで開いたままでは通知が届きません。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の構造 |
| `style.css` | スタイル（ダークテーマ） |
| `app.js` | ロジック全般（描画・保存・通知） |
| `sw.js` | Service Worker（オフラインキャッシュ） |
| `manifest.json` | PWA の設定 |

| `gen-icons.js` | アイコン生成スクリプト（再生成時のみ使用） |

# えいご練習（`english/`）

英語がほぼ初めての人向けの、**読む・打つ**を中心にした練習アプリ（PWA）。スケジュールアプリとは別アプリとして `english/` に入っています。

## 練習の種類

- **単語を読む** — 英単語を見て、意味を4択で選ぶ
- **単語を打つ** — 日本語を見て英単語を入力（文字数ヒント／1文字ずつヒントあり）。間違えたら正解をその場で打ち直す
- **文を読む** — 短い英文の意味を3択で選ぶ
- **文を並べる** — 単語チップをタップして語順どおりに並べる
- **文を写して打つ** — お手本を見ながら英文を入力。単語ごとに正誤を色で表示
- **文を思い出して打つ** — 日本語だけを見て英文を入力（1語ずつヒントあり）

## 今日のメニュー

ホーム画面の「今日のメニュー」から始めると、進み具合に合わせた練習が順番に出ます。

- ステップ1：単語に慣れる（単語を読む・打つ）
- ステップ2：単語を増やして文に触れる（＋文を読む）
- ステップ3：文を組み立てて打つ（文を並べる・写して打つ）
- ステップ4：文を思い出して打つ

復習が溜まっている練習があれば先頭に入ります。量は1日の目標時間（5／10／15／30分）に合わせて変わります。

## 学習時間

- ホームに「今日の学習時間」「目標までの残り」「合計」を表示
- 記録画面に「今日・直近7日・合計」と、直近7日の棒グラフ（目標達成日は緑）
- 練習中の操作の間隔から計算し、1分以上操作がない間やアプリを閉じている間は数えません

## 仕組み

- 収録：基本単語 151語（11カテゴリ）、短文 44文（`english/data.js` に追記すれば増やせます）
- 間違えた問題はセッションの最後にもう一度出題
- 間隔反復：正解するたびに次の出題が 1→3→7→14→30日後と伸び、間違えるとすぐ再出題
- 判定では大文字・小文字と「. , ? !」を区別しません
- 🔊 ボタンで発音を再生（ブラウザの読み上げ機能を使用。声は端末によって異なります）
- 記録はブラウザの localStorage に保存（サーバー送信なし）

ローカルでは `node serve.js` を実行し、http://localhost:5173/english/ を開きます。
