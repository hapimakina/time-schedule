# タイムスケジュール

1日のタイムラインでスケジュールを管理する PWA（Progressive Web App）。

## 機能

- **タイムライン表示** — 24時間の時間軸に沿って、その日の予定を表示。今日は現在時刻に赤いラインが出ます。
- **単発の予定** — 特定の日付だけのイベント。
- **繰り返しの予定** — 曜日を指定して毎週繰り返すルーティン。
- **編集・削除** — 予定をタップして内容を変更、または削除。
- **色分け** — 6色から選択。時間が重なる予定は自動で横並び表示。
- **通知** — 開始時刻にブラウザ通知（アプリを開いている間のみ）。
- **オフライン対応** — Service Worker でキャッシュするため、電波がなくても開けます。

データはすべてブラウザの localStorage に保存されます。サーバーには一切送信されません。

## iPhone でホーム画面に追加する

1. Safari で公開URLを開く
2. 下部の共有ボタン（□に↑）をタップ
3. 「ホーム画面に追加」を選択
4. 名前を確認して「追加」

これでアプリのように全画面で起動します。

## ローカルで動かす

```bash
node serve.js
```

http://localhost:5173 で開きます。

## 通知について

iOS の標準「時計」アプリのアラームに、外部アプリからプログラムで予定を追加する公開APIは存在しません。そのためこのアプリは自前のブラウザ通知でお知らせします。

iOS でプッシュ通知を使うには、**ホーム画面に追加したうえで**そのアイコンから起動する必要があります（iOS 16.4 以降）。Safari のタブで開いたままでは通知が届きません。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の構造 |
| `style.css` | スタイル（ダークテーマ） |
| `app.js` | ロジック全般（描画・保存・通知） |
| `sw.js` | Service Worker（オフラインキャッシュ） |
| `manifest.json` | PWA の設定 |
| `icons/` | アプリアイコン |
| `serve.js` | ローカル確認用の簡易サーバー |
| `gen-icons.js` | アイコン生成スクリプト（再生成時のみ使用） |
